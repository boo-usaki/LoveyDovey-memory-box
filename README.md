# 伴侶記憶匣

*made quietly by Boo_usaki*<br>
<sub>created with Claude Opus 5.5 &amp; Codex (Sol 5.6)</sub>

把妳和 AI 伴侶的長對話，整理成一張張可以複製下來、再搬進「卿卿我我」的記憶卡片。

👉 **[打開伴侶記憶匣](https://boo-usaki.github.io/LoveyDovey-memory-box/)**

不懂程式也可以使用。記憶匣只有一個正式網址，就是上面這個；電腦和手機都從這裡打開。記憶預設只留在妳現在使用的瀏覽器，想讓手機和電腦看到同一份內容時，再開啟同步即可。

## 這個工具會做什麼？

- **記憶**：每幾輪整理成一張卡片，並記住整理到哪裡，方便查看與搬運。
- **事件**：挑出關係進展、劇情、日常或人物設定等重要事件，接著寫進「卿卿我我」的事件欄。
- **整理進度**：記住上次整理到哪裡，下次從後面接續。
- **待轉移清單**：貼進「卿卿我我」後按「已轉移」，畫面就只留下還沒搬完的內容。

記憶匣負責保存和排版；對話內容由妳選擇的 AI 整理。

## 使用流程

整理在電腦上做，手機只用來複製。

1. **在電腦打開正式網站**：[boo-usaki.github.io/LoveyDovey-memory-box](https://boo-usaki.github.io/LoveyDovey-memory-box/)。只在這台電腦使用時，不用登入，也不用設定。
2. **決定怎麼把整理結果帶到手機**：想讓手機和電腦一直保持一致，再到左側「同步與備份」設定 GitHub 同步；不想使用 GitHub 金鑰也可以，等 AI 整理完後再下載備份檔搬到手機。
3. **新增伴侶，選「記憶」或「事件」**：按左側「＋ 新增伴侶」輸入名字，再到伴侶頁上方填妳在這段對話裡的名字。
4. **在網頁上傳對話檔，請 AI 整理**：
   - **這次對話能操作瀏覽器或電腦**：Codex、Claude 或其他有這項能力的 AI，都可以直接完成。跟它說「打開伴侶記憶匣，幫我把〇〇的對話整理成記憶（或 FIR 事件），直接寫進去。」它會打開正式網站，讀取妳已上傳的對話檔，整理後寫進記憶匣；妳不用複製指令，也不用把 AI 回覆貼回來。
   - **這次對話不能操作瀏覽器或電腦**：按「複製指令」，連同對話檔一起交給 AI；它回覆後，按「貼上回覆」把整段回覆貼回來。不管回覆看起來像一般文字還是程式碼，整段貼回來即可。
5. **把整理結果帶到手機**，二選一：
   - **想要自動同步**：在電腦設定 GitHub 同步後，按「複製手機連線碼」；再用手機瀏覽器打開同一個正式網址，到「同步與備份」貼上連線碼並按「連線」。手機不用安裝 GitHub App，也不用登入 GitHub。
   - **不想使用 GitHub 金鑰**：在電腦按「下載備份檔」，把下載的 `.json` 檔用自己的 LINE、Discord 或其他私人方式傳到手機；手機打開正式網站，到「同步與備份 → 還原備份 → 選擇備份檔」。這是一次性搬運，以後電腦有新內容就要再搬一次。只想帶走少量內容時，也可以直接把卡片複製成文字傳給自己，不必還原整份備份。
6. **在手機複製，貼進「卿卿我我」**：按「複製整則」；事件則分別複製大標、小標和內文，自己貼進「卿卿我我」。貼好後按「已轉移」，電腦那邊也會一起更新。

想先換格式、字數或事件類別，再打開左側「記憶格式與規則」。不修改也能直接使用預設值。

## 整理記憶

「記憶」適合按照對話順序保存一段段共同經歷。預設每 10 輪整理一張卡片；伴侶一次回覆加上妳一次回覆，算一輪。

頁面會自動記住整理進度。每次都匯出完整對話時，用「輪數」接續；每次只匯出新的一段時，用「日期」接續。

每張卡片都可以：

- 複製整則
- 標記為「已轉移」
- 在「待轉移／已轉移」之間切換查看

<details>
<summary><strong>看看預設的記憶格式</strong></summary>

```text
# [標題]

- 地點：
- 場景概要：
- 關鍵詞：
- 關鍵對話：
- 情感變化及影響：
- {伴侶}覺得重要的事：
```

`{伴侶}` 會自動換成伴侶名字。預設字數上限是 500 字，超過時頁面會標示出來；格式、輪數和字數都能在「記憶格式與規則」修改。

</details>

## 整理事件

「事件」適合保存真正重要、之後希望伴侶記得的事情，例如關係進展、劇情、日常紀錄或人物設定。

1. 在伴侶頁面右上角切換到「事件」。
2. 選擇事件類別和要整理的日期範圍。
3. 請 AI 整理：這次對話能操作瀏覽器或電腦時，Codex、Claude 或其他有這項能力的 AI 可以直接讀取對話檔並寫入；不能操作時，請按「貼上回覆」把 AI 的結果貼回記憶匣。頁面會自動編號，接到目前的事件欄。
4. 按事件欄上的「大標」「小標」「內文」，分別複製到「卿卿我我」。

匯入後，記憶匣會自動記住整理到哪一天。如果 AI 漏寫日期、日期對不上或超出妳選的範圍，頁面會提醒妳檢查，不會擅自跳過那段對話。

每則事件都可以複製、編輯、刪除或標記為「已轉移」。

當下一則放不進目前事件欄時，頁面會顯示一個不會自己消失的提醒，直到妳選好：

- 改短一點，放進這欄；或
- 結束目前這欄，開新的一欄。

如果單則內容本身就超過字數上限，只會請妳改短，不會先把超長內容存進去。

<details>
<summary><strong>事件代號、欄位與接續設定</strong></summary>

- 預設類別有 FIR（關係重大進展）、EV（劇情進展）、DIA（日常紀錄）、CS（人物設定）、STORY（人物故事）。名稱和類別都可以修改。
- 不喜歡 `[FIR-05-02]` 這類代號，可以在「記憶格式與規則 → 事件格式」改成「不用代號」。
- 「卿卿我我」裡已經有寫到一半的事件欄時，在事件頁按「接著寫」，貼上原有內文；記憶匣會算出下一個編號。
- 刪除一則事件後，後續編號不會倒退或重複使用。
- 預設每則事件最多 500 字、每欄最多 2000 字，兩個數字都能修改。

預設格式：

```text
[{代號}-{欄號}-{則號}] {關鍵字}
時間：
地點：
細節：
```

</details>

## 資料存在哪裡？

| 使用方式 | 記憶存放位置 | 手機、電腦共用 |
| --- | --- | --- |
| 沒有開同步 | 目前這個瀏覽器 | 不會 |
| 開啟 GitHub 同步 | 妳 GitHub 帳號裡一份不公開列出的 Gist | 會 |

- GitHub 在這裡負責保存一份不公開列出的 Secret Gist。電腦和手機上的記憶匣拿同一組連線碼去讀寫它，所以兩邊會看到相同內容；手機不用安裝 GitHub App，也不用登入 GitHub。
- **Secret Gist 不等於真正的私人檔案。** 它不會出現在 GitHub 的公開列表或搜尋裡，但只要有人拿到那份 Gist 的網址，仍然可以看到裡面的記憶內容。這是 [GitHub 官方說明](https://docs.github.com/en/get-started/writing-on-github/editing-and-sharing-content-with-gists/creating-gists) 明確寫出的限制；非常敏感、不希望任何網址外洩風險的內容，請不要開啟這項同步，改用本機加上自行保管的備份。
- 每個人打開正式網址，看到的都是自己的資料；分享網址不會把妳的記憶一起分享出去。
- 上傳的原始對話檔不包含在同步或備份裡。換裝置後如需重新整理，請在新裝置再次上傳。
- 記憶匣本身不會把大家的內容集中存到作者帳號；但妳把對話交給哪個 AI 整理，仍適用那個 AI 服務自己的隱私與資料規則。
- 建議偶爾到「同步與備份」複製或下載一份備份。備份包含記憶、事件和設定，不含原始對話檔。
- 「還原備份」會用備份內容取代目前全部資料；還原前建議先替現況再留一份備份。
- GitHub 的 `Expiration` 是「有效期限」：`7 / 30 / 60 / 90 days` 是幾天後到期，`Custom` 是自選日期，`No expiration` 是永不過期。建議選 `90 days`；到期後同步會停止，再產生一組新的即可。永不過期雖然方便，但金鑰若外洩，風險也會一直存在。
- **金鑰實際去哪裡？** 妳貼上的金鑰只會保存在這台裝置的瀏覽器裡，連線時送到 GitHub API；不會送到記憶匣作者的帳號、不會寫進 Gist，也不會放進下載的備份檔。它並不是加密保管在瀏覽器裡，因此仍要把使用中的裝置、瀏覽器帳號和擴充功能保護好。
- GitHub 的 `gist` 權限能讀寫妳帳號裡的 Gist，但不包含 GitHub repository 權限。手機連線碼裡含有同一把金鑰和 Gist 編號，安全性等同金鑰；不要貼到群組、公開頻道或交給別人。
- 「中斷連線」只會刪除目前這台裝置瀏覽器裡保存的金鑰，不會讓金鑰本身失效。裝置遺失或懷疑外洩時，請到 GitHub 的金鑰設定頁刪除（撤銷）那把金鑰。
- **不想使用 GitHub 金鑰，也能搬到手機**：AI 整理完成後，在電腦下載備份檔，再把 `.json` 檔用自己的 LINE、Discord 或其他私人方式傳到手機，於手機版記憶匣按「還原備份」。備份檔含有妳的記憶、事件和設定，傳送服務可能保留檔案，請依自己的隱私需求選擇管道。這是一次性搬運，不會自動同步。
- 左側「配色」有草莓氣泡、法式桃紅、午夜唱片和芋泥啵啵四套；只會改變外觀，每台裝置會各自記住選擇。

## 常見問題

**一定要設定同步嗎？**

不用。只在同一個瀏覽器使用時可以完全不設定；要搬到手機時也能改用「下載備份檔 → 在手機還原備份」。只有想讓手機和電腦之後自動保持一致，才需要 GitHub 同步。

**AI 一定要能操作網頁嗎？**

不用。如果這次 Codex、Claude 或其他 AI 的對話具備瀏覽器／電腦操作能力，它可以直接打開正式網站、讀取已上傳的對話檔，整理後寫進記憶匣。沒有這項能力時，使用「複製指令」與「貼上回覆」即可；不是只要使用 Codex 或 Claude，就一定能直接操作。

**一定要使用事件代號嗎？**

不用。事件格式可以切換成「不用代號」。

**格式一定要照預設嗎？**

不用。記憶與事件格式、字數、事件類別都能修改；每位伴侶也能另外調整自己的記憶 AI 指令。事件需要補充規則時，請到「事件格式 → 其他給 AI 的提醒」。

**手機可以做什麼？**

手機用來查看、複製和標記「已轉移」。上傳對話檔、請 AI 整理和設定同步，請在電腦上做。
