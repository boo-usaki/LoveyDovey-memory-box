# 伴侶記憶匣

*made quietly by Boo_usaki*<br>
<sub>created with Claude Opus 5.5 &amp; Codex (Sol 5.6)</sub>

把妳和 AI 伴侶的長對話，整理成一張張可以複製下來、再搬進「卿卿我我」的記憶卡片。

👉 **[打開伴侶記憶匣](https://boo-usaki.github.io/LoveyDovey-memory-box/)**

不懂程式也可以使用。記憶匣只有一個正式網址，就是上面這個；電腦和手機都從這裡打開。記憶只留在妳現在使用的瀏覽器，不需要 GitHub 帳號，也不會自動上傳。要帶到手機時，下載一份有密碼保護的備份即可。

## 這個工具會做什麼？

- **記憶**：每幾輪整理成一張卡片，並記住整理到哪裡，方便查看與搬運。
- **事件**：挑出關係進展、劇情、日常或人物設定等重要事件，接著寫進「卿卿我我」的事件欄。
- **整理進度**：記住上次整理到哪裡，下次從後面接續。
- **待轉移清單**：貼進「卿卿我我」後按「已轉移」，畫面就只留下還沒搬完的內容。

記憶匣負責保存和排版；對話內容由妳選擇的 AI 整理。

## 使用流程

整理在電腦上做，手機只用來複製。

1. **在電腦打開正式網站**：[boo-usaki.github.io/LoveyDovey-memory-box](https://boo-usaki.github.io/LoveyDovey-memory-box/)。不用登入，也不用建立 GitHub 帳號。
2. **新增伴侶，選「記憶」或「事件」**：按左側「＋ 新增伴侶」輸入名字，再到伴侶頁上方填妳在這段對話裡的名字。
3. **在網頁上傳對話檔，請 AI 整理**：
   - **這次對話能操作瀏覽器或電腦**：Codex、Claude 或其他有這項能力的 AI，都可以直接完成。跟它說「打開伴侶記憶匣，幫我把〇〇的對話整理成記憶（或 FIR 事件），直接寫進去。」它會打開正式網站，讀取妳已上傳的對話檔，整理後寫進記憶匣；妳不用複製指令，也不用把 AI 回覆貼回來。
   - **這次對話不能操作瀏覽器或電腦**：按「複製指令」，連同對話檔一起交給 AI；它回覆後，按「貼上回覆」把整段回覆貼回來。不管回覆看起來像一般文字還是程式碼，整段貼回來即可。
4. **在電腦下載手機備份**：打開左側「手機備份」，設定一組至少 4 個字元、內容不限的密碼，再按「下載手機備份」。備份會先在電腦裡加密；密碼不會被記住或上傳。
5. **把備份傳到手機並復原**：用自己信任的方式把檔案傳到手機。手機打開同一個正式網址，到「手機備份」選擇檔案，輸入同一組密碼後復原。電腦有新內容時，再重新下載和搬一次。
6. **在手機複製，貼進「卿卿我我」**：按「複製整則」；事件則分別複製大標、小標和內文，自己貼進「卿卿我我」。手機和電腦不會自動同步；手機上的「已轉移」狀態也不會傳回電腦。

想先換格式、字數或事件類別，再打開左側「記憶格式與規則」。不修改也能直接使用預設值。

## 整理記憶

「記憶」適合按照對話順序保存一段段共同經歷。預設每 10 輪整理一張卡片；伴侶一次回覆加上妳一次回覆，算一輪。

頁面會自動記住整理進度。每次都匯出完整對話時，用「輪數」接續；每次只匯出新的一段時，用「日期」接續。

每張卡片都可以：

- 複製整則
- 標記為「已轉移」
- 在「待轉移／已轉移」之間切換查看

<details>
<summary><strong>看看預設的記憶格式</strong></summary>

```text
# [標題]

- 地點：
- 場景概要：
- 關鍵詞：
- 關鍵對話：
- 情感變化及影響：
- {伴侶}覺得重要的事：
```

`{伴侶}` 會自動換成伴侶名字。預設字數上限是 500 字，超過時頁面會標示出來；格式、輪數和字數都能在「記憶格式與規則」修改。

</details>

## 整理事件

「事件」適合保存真正重要、之後希望伴侶記得的事情，例如關係進展、劇情、日常紀錄或人物設定。

1. 在伴侶頁面右上角切換到「事件」。
2. 選擇事件類別和要整理的日期範圍。
3. 請 AI 整理：這次對話能操作瀏覽器或電腦時，Codex、Claude 或其他有這項能力的 AI 可以直接讀取對話檔並寫入；不能操作時，請按「貼上回覆」把 AI 的結果貼回記憶匣。頁面會自動編號，接到目前的事件欄。
4. 按事件欄上的「大標」「小標」「內文」，分別複製到「卿卿我我」。

匯入後，記憶匣會自動記住整理到哪一天。如果 AI 漏寫日期、日期對不上或超出妳選的範圍，頁面會提醒妳檢查，不會擅自跳過那段對話。

每則事件都可以複製、編輯、刪除或標記為「已轉移」。

當下一則放不進目前事件欄時，頁面會顯示一個不會自己消失的提醒，直到妳選好：

- 改短一點，放進這欄；或
- 結束目前這欄，開新的一欄。

如果單則內容本身就超過字數上限，只會請妳改短，不會先把超長內容存進去。

<details>
<summary><strong>事件代號、欄位與接續設定</strong></summary>

- 預設類別有 FIR（關係重大進展）、EV（劇情進展）、DIA（日常紀錄）、CS（人物設定）、STORY（人物故事）。名稱和類別都可以修改。
- 不喜歡 `[FIR-05-02]` 這類代號，可以在「記憶格式與規則 → 事件格式」改成「不用代號」。
- 「卿卿我我」裡已經有寫到一半的事件欄時，在事件頁按「接著寫」，貼上原有內文；記憶匣會算出下一個編號。
- 刪除一則事件後，後續編號不會倒退或重複使用。
- 預設每則事件最多 500 字、每欄最多 2000 字，兩個數字都能修改。

預設格式：

```text
[{代號}-{欄號}-{則號}] {關鍵字}
時間：
地點：
細節：
```

</details>

## 資料存在哪裡？

- 記憶、事件和設定只保存在目前使用的瀏覽器裡；網站不會替妳建立帳號，也不會把內容自動上傳到作者或 GitHub。
- 每個人打開正式網址，看到的都是自己的資料；分享網站網址不會把妳的記憶一起分享出去。
- 上傳的原始對話檔只留在上傳它的那台裝置，不會放進手機備份。換裝置後如需重新整理，請在新裝置再次上傳。
- 手機備份包含記憶、事件、事件欄、伴侶設定、格式和 AI 指令修改。密碼只在目前裝置上用來加密或復原，不會被記住、上傳或寫進備份檔；網站不會把密碼傳給作者、GitHub 或傳送備份檔的服務。
- 備份加密主要是為了防止檔案不小心傳錯聊天室、群組，或分享連結誤傳時，沒有密碼的人直接看到裡面的私密內容。可以用 LINE、Discord、雲端硬碟、隔空投送、快速分享或傳輸線把備份帶到手機。
- 忘記密碼時，只要電腦瀏覽器裡的原始資料還在，就能重新下載一份。若只剩備份檔，沒有密碼就無法復原。
- 復原備份會用檔案內容取代目前這台裝置的全部記憶、事件和設定。手機與電腦不會自動同步；電腦有新內容時，要重新下載並搬到手機。
- 記憶匣本身不會把大家的內容集中存到作者帳號；但妳把對話交給哪個 AI 整理，仍適用那個 AI 服務自己的隱私與資料規則。
- 左側「配色」有草莓氣泡、法式桃紅、午夜唱片和芋泥啵啵四套；只會改變外觀，每台裝置會各自記住選擇。

## 常見問題

**需要 GitHub 帳號或金鑰嗎？**

不用。記憶匣沒有 GitHub 同步，也不需要登入。要搬到手機時，使用「下載手機備份 → 在手機復原」即可。

**AI 一定要能操作網頁嗎？**

不用。如果這次 Codex、Claude 或其他 AI 的對話具備瀏覽器／電腦操作能力，它可以直接打開正式網站、讀取已上傳的對話檔，整理後寫進記憶匣。沒有這項能力時，使用「複製指令」與「貼上回覆」即可；不是只要使用 Codex 或 Claude，就一定能直接操作。

**一定要使用事件代號嗎？**

不用。事件格式可以切換成「不用代號」。

**格式一定要照預設嗎？**

不用。記憶與事件格式、字數、事件類別都能修改；每位伴侶也能另外調整自己的記憶 AI 指令。事件需要補充規則時，請到「事件格式 → 其他給 AI 的提醒」。

**手機可以做什麼？**

手機用來查看、複製和標記「已轉移」。上傳對話檔、請 AI 整理和下載備份，請在電腦上做。手機上的變更不會傳回電腦。
