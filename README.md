# 伴侶記憶匣

*made quietly by Boo_usaki*

把和伴侶的對話整理成一則一則的記憶卡片：自訂自己的記憶格式、交給 AI 整理、貼回來就變成卡片，一鍵複製整則、轉移完就收起來。

只有一個 `index.html`，不需要安裝、不需要伺服器。記憶預設只存在妳自己的瀏覽器裡；只有妳自己開啟同步時，才會存進妳自己帳號裡的私人 Gist 或 Claude 帳號，不會傳到其他地方。

## 怎麼用

1. **設定格式**：打開「記憶格式與規則」，照自己習慣寫記憶格式。第一行用 `#` 開頭當標題，之後每行一個欄位：

   ```
   # [標題]

   - 地點：
   - 場景概要：
   - 關鍵詞：
   - 關鍵對話：
   - 情感變化及影響：
   - {伴侶}覺得重要的事：
   ```

   - `{伴侶}` 會自動換成伴侶的名字
   - 欄位名稱有「關鍵詞／關鍵字」會顯示成標籤，有「對話」會顯示成引言
   - 可以設定每幾輪整理成一則（預設 10 輪），以及只整理某個範圍

2. **新增伴侶**：左側按「＋ 新增伴侶」，填妳在這段對話裡的名字。之後在伴侶頁面照 1、2、3 步驟走：上傳對話檔 → 複製指令交給 AI → 貼回 AI 的回覆。

3. **交給 AI 整理**：在伴侶頁面按「複製指令」，連同對話檔一起交給妳的 AI（Claude、ChatGPT、Gemini 都可以）。AI 會回一段 JSON。

4. **貼回回覆**：在伴侶頁面按「貼上回覆」，把 AI 的回覆貼上（或直接選檔案）。也可以貼照格式寫好的文字，每則用 `#` 開頭。

5. **使用**：左邊切換伴侶，按「複製整則」貼到妳的平台，貼完按「已轉移」收起來。

6. **換配色**：左側「配色」可以換頁面顏色，有草莓氣泡、法式桃紅、午夜唱片、芋泥啵啵四套。只換樣子，記憶不會變；每台裝置各自記得自己選的配色。

## 在 Claude 上使用（同步到自己的 Claude 帳號）

用 Claude 的話，可以把頁面放進自己的 Claude 帳號，電腦、手機的 Claude 都能打開同一份，記憶會自動同步，也可以直接請 Claude 整理並寫入，不用開側欄。

**第一次設定（只要做一次）**

資料會存在「頁面主人」的帳號裡，所以每個人都要有自己的一份。打開別人分享的 Claude 連結只能看，記憶存不進自己的帳號。

1. 下載這個 repository 裡的 `index.html`（點檔案 → 右上角下載按鈕；或在頁面的「使用說明 → 用 Claude」按「下載頁面檔」）
2. 在電腦開一個新的 Claude 對話，附上 `index.html`，然後說：
   > 幫我把這個網頁發佈成我自己的 Artifact，要開啟資料庫（db）和使用者（user）功能，發佈好幫我釘選到側邊欄。
3. Claude 做好會出現一張頁面卡片，點開後左上角顯示「已同步到 Claude 帳號」就成功了
4. 之後電腦、手機都從 Claude 的側邊欄打開這份

**之後每次整理**

1. 在伴侶頁面按「複製指令」
2. 到任何一個 Claude 對話（電腦、手機都可以）貼上、附上對話檔，再補一句「整理好直接寫進伴侶記憶匣」
3. Claude 會把記憶寫進頁面、告訴妳寫了幾則，整理進度也會自動往前
4. 在手機的 Claude App 從側邊欄打開頁面，複製整則、貼到伴侶 App、按「已轉移」

## 整理進度

每次匯入記憶，頁面會記下這位伴侶「已整理到第幾輪」。下次按「複製指令」，指令會自動寫上「從第幾輪開始、編號接續」，AI 就不會重複整理。

如果每次只匯出新的一段對話，可以在「整理進度 → 修改」改成「用日期接續」，AI 會在每則記憶附上日期，頁面記下整理到哪一天。進度也可以手動修改。

## 資料存在哪裡、怎麼跨裝置

- **在 Claude 裡打開**：自動同步到自己的 Claude 帳號，電腦和手機的 Claude 都看得到，不用設定。
- **從 GitHub 等網址打開**：預設只存在那個瀏覽器。到左側「同步與備份」用自己的 GitHub 帳號連線（產生一組只開放 gist 權限的金鑰，頁面有一步一步的教學），記憶會存進自己帳號裡的一份私人 Gist。手機打開同一個網址，貼上「手機連線碼」就會看到一樣的內容。
- 兩台裝置同時新增記憶也不會互相蓋掉，會合併在一起。
- 連線碼等同金鑰，只傳給自己；借別人的電腦用完記得「中斷連線」。

## 放到 GitHub Pages

1. 在 GitHub 建一個新的 repository，上傳 `index.html`、`README.md` 和 `AGENT.md`
2. 到 repository 的 **Settings → Pages**
3. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save
4. 等一兩分鐘，頁面上方會出現網址，分享給朋友就能用（每個人用自己的 GitHub 同步，互相看不到）

每個人打開的都是自己的記憶匣，互相看不到彼此的資料。

## 讓 agent 直接操作頁面

用 Claude in Chrome 側欄、Claude 桌面版的內建瀏覽器、Codex 這類能操作網頁的 agent 打開頁面，它可以透過頁面提供的 `window.memoryShelf` 讀指令、讀最新上傳的對話檔、整理後直接寫入記憶匣。只要跟 agent 說「幫我整理〇〇的對話，寫進記憶匣」就好。詳細用法寫在 `AGENT.md` 最後。

## 修改 AI 整理指令

每位伴侶頁面的「AI 整理指令」可以手動修改措辭，改過的地方會記住；之後換名字、整理進度往前、改規則，修改都還會保留。

## 讓 agent 自己讀指令

想讓 agent 自己去讀指令，有兩種做法：

- **agent 能讀網址**：repository 裡的 `AGENT.md` 是預設格式的指令。跟 agent 說「先讀 `https://raw.githubusercontent.com/<帳號>/<repository>/main/AGENT.md`，再照指令整理我給的對話檔」。想換成自己的格式，就把頁面上自訂好的指令貼進自己 fork 的 `AGENT.md`。
- **agent 能讀資料夾**：在頁面按「下載成 AGENT.md」，放進 agent 的工作資料夾，請它讀這個檔案再開始整理。用 Claude 的話，也可以把指令貼進 Project 的說明，之後每次丟對話檔就好。

注意：頁面上的設定存在瀏覽器裡，agent 打開網頁是看不到的，所以要用上面兩種方式把指令交給它。

## JSON 格式

如果妳的 agent 可以直接產生檔案，請它輸出符合下面格式的 `.json`，再到伴侶頁面按「貼上回覆」選擇檔案即可：

```json
[
  {
    "companion": "伴侶名字",
    "rounds": "1-10",
    "title": "記憶標題",
    "fields": {
      "地點": "……",
      "關鍵詞": ["詞語1", "詞語2"],
      "關鍵對話": "名字：「……」\n名字：「……」",
      "{伴侶}覺得重要的事": "……"
    }
  }
]
```

`fields` 的欄位名稱要跟格式設定裡的一樣。同一位伴侶、同樣 `rounds` 的記憶再次匯入時，會更新原本那則，不會重複。
