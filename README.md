# 伴侶記憶匣

*made quietly by Boo_usaki*<br>
<sub>created with Claude Opus 5.5 &amp; Codex (Sol 5.6)</sub>

把妳和 AI 伴侶的長對話，整理成一張張可以複製下來、再搬進「卿卿我我」的記憶卡片。

👉 **[打開伴侶記憶匣](https://boo-usaki.github.io/LoveyDovey-memory-box/)**

不懂程式也可以使用。記憶匣只有一個正式網址，就是上面這個；電腦和手機都從這裡打開。記憶只留在妳現在使用的瀏覽器，不需要 GitHub 帳號，也不會自動上傳。要帶到手機時，下載一份有密碼保護的備份即可。

## 這個工具會做什麼？

- **記憶**：每幾輪整理成一張卡片，並記住整理到哪裡，方便查看與搬運。
- **事件**：挑出關係進展、劇情、日常或人物設定等重要事件，接著寫進「卿卿我我」的事件欄。
- **整理進度**：記住上次整理到哪裡，下次從後面接續。
- **待轉移清單**：貼進「卿卿我我」後按「已轉移」，畫面就只留下還沒搬完的內容。

記憶匣負責保存和排版；對話內容由妳選擇的 AI 整理。

## 使用流程

整理在電腦上做；手機負責複製、標記已轉移，再把最新進度備份回電腦。

1. **在電腦打開正式網站**：[boo-usaki.github.io/LoveyDovey-memory-box](https://boo-usaki.github.io/LoveyDovey-memory-box/)。不用登入，也不用建立 GitHub 帳號。
2. **新增一位伴侶**：按左側「＋ 新增伴侶」，輸入對方的名字，再按「新增」。右邊會自動打開這位伴侶的頁面。
3. **填妳在這段關係中的名字**：在右邊頁面的最上方，填入妳在這段關係中的名字。
4. **設定整理格式，或直接使用預設**：打開左側「記憶格式與規則」，用上方的「記憶／事件」切換要調整的設定。想自訂就修改；不想改就保留預設。
5. **選擇「記憶」或「事件」**：回到伴侶頁，依這次想整理的內容切換。一般對話選「記憶」；只整理特定重點時選「事件」，再設定日期範圍。AI 會替每則事件建議類別，匯入前可以逐則改正。
6. **上傳對話檔，請 AI 整理**：
   - **AI 可以直接打開網站時**：先把對話檔上傳到伴侶頁，再直接請 AI 讀取這個網頁，告訴它要整理哪位伴侶的「記憶」或「事件」。它會讀取已上傳的對話檔；事件會先停在分類確認畫面，妳確認後才寫進記憶匣。不用複製指令，也不用把 AI 回覆貼回來。
   - **AI 只能在對話裡回覆文字時**：按「複製指令」，連同對話檔一起交給 AI；它回覆後，按「貼上回覆」把整段回覆貼回來。不管回覆看起來像一般文字還是程式碼，整段貼回來即可。
7. **在電腦下載備份**：打開左側「備份與搬移」，設定一組至少 4 個字元、內容不限的密碼，再按「下載備份」。檔名會是 `memory_box-backup-YYYY-MM-DD.memorybox`，日期是下載當天。備份會先在電腦裡加密；密碼不會被記住或上傳。
8. **把備份傳到手機並復原**：用自己信任的方式把檔案傳到手機。手機打開同一個正式網址，到「備份與搬移」選擇備份檔，輸入同一組密碼後復原。電腦有新內容時，再重新下載和搬一次。
9. **在手機複製，貼進「卿卿我我」**：按「複製整則」；事件則分別複製大標、小標和內文，自己貼進「卿卿我我」。貼完後，在記憶匣標記「已轉移」。
10. **把手機進度帶回電腦**：完成手機操作後，在手機的「備份與搬移」下載一份新備份，傳回電腦並復原。下次整理前先完成這一步，電腦就會接著手機最新的「已轉移」狀態繼續。

## 整理記憶

「記憶」適合按照對話順序保存一段段共同經歷。預設每 10 輪整理一張卡片；伴侶一次回覆加上妳一次回覆，算一輪。

頁面會自動記住整理進度。每次都匯出完整對話時，用「輪數」接續；每次只匯出新的一段時，用「日期」接續。

每張卡片都可以：

- 複製整則
- 標記為「已轉移」
- 在「待轉移／已轉移」之間切換查看

<details>
<summary><strong>看看預設的記憶格式</strong></summary>

```text
# [標題]

- 地點：
- 場景概要：
- 關鍵詞：
- 關鍵對話：
- 情感變化及影響：
```

`{伴侶}` 會自動換成伴侶名字。預設字數上限是 500 字，超過時頁面會標示出來；格式、輪數和字數都能在「記憶格式與規則」修改。

## 整理事件

「事件」適合保存之後希望伴侶記得、再次聊起時能接得上話的事情，例如關係進展、劇情、日常紀錄或人物設定。

1. 在伴侶頁面右上角切換到「事件」。
2. 設定要整理的日期範圍。
3. 請 AI 整理：這次對話能操作瀏覽器或電腦時，Codex、Claude 或其他有這項能力的 AI 可以直接讀取對話檔；不能操作時，請按「貼上回覆」把 AI 的結果貼回記憶匣。
4. 逐則確認 AI 建議的事件類別，覺得分錯時直接改成妳認為正確的類別。確認後頁面才會自動編號，接到對應的事件欄。
5. 按事件欄上的「大標」「小標」「內文」，分別複製到「卿卿我我」。

匯入後，記憶匣會自動記住整理到哪一天。如果 AI 漏寫日期、日期對不上或超出妳選的範圍，頁面會提醒妳檢查，不會擅自跳過那段對話。

每則事件都可以複製、編輯、刪除或標記為「已轉移」。

當下一則放不進目前事件欄時，頁面會顯示一個不會自己消失的提醒，直到妳選好：

- 改短一點，放進這欄；或
- 結束目前這欄，開新的一欄。

如果單則內容本身就超過字數上限，只會請妳改短，不會先把超長內容存進去。

<details>
<summary><strong>事件代號、欄位與接續設定</strong></summary>

- 預設類別有 FIR（重大事件紀錄）、EV（劇情進展紀錄）、DIA（日常紀錄）、CS（人物設定）、STORY（人物故事）、EST（資產）。EST 用來紀錄角色已公開資產。
- 事件格式可以選「預設代號」或「自訂格式」。預設代號整套直接使用；自訂格式的大標、小標和內文從空白開始，事件代號與類別是選填，整欄留空就代表不用代號。
- 「卿卿我我」裡已經有寫到一半的事件欄時，在事件頁按「接著寫」，貼上原有內文；記憶匣會算出下一個編號。
- 刪除一則事件後，後續編號不會倒退或重複使用。
- 預設每則事件最多 500 字、每欄內文最多 2000 字；同一欄裡的多則事件會以 `---` 分隔，盡量填滿後才開下一欄。

預設格式：

```text
大標
[代號-第幾篇] 類別名稱

小標
YYYY/MM/DD-現在｜依事件地點進行已發生事件紀錄更新

內文
[代號-第幾篇-之幾] 關鍵字
時間：YYYY/MM/DD 時段
地點：……
細節：
- ……
- ……

---

[代號-第幾篇-之幾] 關鍵字
……
```

AI 回傳中的 `date` 只供記憶匣排序和接續整理，不會出現在事件內文；`date` 和內文的「時間」都依設定使用現實時間或狀態欄時間。狀態欄沒有提供時間時，改用現實時間。

</details>

## 資料存在哪裡？

- 記憶、事件和設定只保存在目前使用的瀏覽器裡；網站不會替妳建立帳號，也不會把內容自動上傳到作者或 GitHub。
- 每個人打開正式網址，看到的都是自己的資料；分享網站網址不會把妳的記憶一起分享出去。
- 上傳的原始對話檔只留在上傳它的那台裝置，不會放進備份檔。換裝置後如需重新整理，請在新裝置再次上傳。
- 備份檔包含記憶、事件、事件欄、伴侶設定、格式和 AI 指令修改。密碼只在目前裝置上用來加密或復原，不會被記住、上傳或寫進備份檔；網站不會把密碼傳給作者、GitHub 或傳送備份檔的服務。
- 備份加密主要是為了防止檔案不小心傳錯聊天室、群組，或分享連結誤傳時，沒有密碼的人直接看到裡面的私密內容。可以用 LINE、Discord、雲端硬碟、隔空投送、快速分享或傳輸線把備份帶到手機。
- 忘記密碼時，只要電腦瀏覽器裡的原始資料還在，就能重新下載一份。若只剩備份檔，沒有密碼就無法復原。
- 復原備份會用檔案內容取代目前這台裝置的全部記憶、事件和設定。手機與電腦不會自動同步；電腦有新內容時，要重新下載並搬到手機，手機標記「已轉移」後也要下載新備份，傳回電腦復原。
- 記憶匣本身不會把大家的內容集中存到作者帳號；但妳把對話交給哪個 AI 整理，仍適用那個 AI 服務自己的隱私與資料規則。
- 左側「配色」有草莓氣泡、法式桃紅、午夜唱片和芋泥啵啵四套；只會改變外觀，每台裝置會各自記住選擇。

## 常見問題

**需要 GitHub 帳號或金鑰嗎？**

不用。記憶匣沒有 GitHub 同步，也不需要登入。要搬到另一台裝置時，使用「下載備份 → 在另一台裝置復原」即可。

**AI 一定要能操作網頁嗎？**

不用。如果這次 Codex、Claude 或其他 AI 的對話具備瀏覽器／電腦操作能力，它可以直接打開正式網站、讀取已上傳的對話檔，整理後寫進記憶匣。沒有這項能力時，使用「複製指令」與「貼上回覆」即可；不是只要使用 Codex 或 Claude，就一定能直接操作。

**一定要使用事件代號嗎？**

不用。切到「自訂格式」，讓「事件代號與類別」保持空白即可。

**格式一定要照預設嗎？**

不用。記憶與事件格式、字數、事件類別都能修改；每位伴侶也能另外調整自己的記憶 AI 指令。事件需要補充規則時，請到「事件格式 → 其他給 AI 的提醒」。

**手機可以做什麼？**

手機用來查看、複製和標記「已轉移」；完成後可以下載新備份，傳回電腦復原。上傳對話檔和請 AI 整理仍在電腦上做；兩台裝置不會自動同步。
