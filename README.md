# 伴侶記憶匣

*made quietly by Boo_usaki*

把和伴侶的對話整理成一則一則的記憶卡片：交給 AI 整理、寫進記憶匣，一鍵複製整則貼到伴侶 App，轉移完就收起來。

👉 直接打開：**https://boo-usaki.github.io/memory-box/**

只有一個 `index.html`，不需要安裝、不需要伺服器。記憶預設只存在妳自己的瀏覽器裡；只有妳自己開啟同步時，才會存進妳自己的 GitHub 私人 Gist 或 Claude 帳號，不會傳到其他地方。每個人打開都是自己的記憶匣，互相看不到。

## 怎麼用

跟頁面左側「使用說明」一樣，分成兩種用法。

### 用 Claude

1. **把頁面放進妳自己的 Claude 帳號（只要做一次）**
   資料會存在「頁面主人」的帳號裡，所以要用妳自己的那一份；打開別人分享的 Claude 連結只能看，記憶存不進妳的帳號。
   - 到這個 repository 點 `index.html`，按右上角的下載按鈕
   - 在電腦開一個新的 Claude 對話，附上 `index.html`，然後說：
     > 幫我把這個網頁發佈成我自己的 Artifact，要開啟資料庫（db）和使用者（user）功能，發佈好幫我釘選到側邊欄。
   - Claude 做好會出現一張頁面卡片，點開後左上角顯示「已同步到 Claude 帳號」就成功了
   - 之後電腦、手機都從 Claude 的側邊欄打開這份就好
2. **設定記憶格式**：左側「記憶格式與規則」填妳要的格式、每幾輪一則、字數上限。預設是「伴侶一則回覆＋妳一則回覆＝一輪」。
3. **新增伴侶，填妳的名字**：左側「＋ 新增伴侶」，再到伴侶頁面上方填妳在這段對話裡的名字。
4. **請 Claude 整理並寫入**：在伴侶頁面按「複製指令」，到 Claude 的對話貼上、附上對話檔，再補一句「整理好直接寫進伴侶記憶匣」。Claude 會把記憶寫進頁面，整理進度也會自動往前。
5. **用手機複製、轉移**：在手機的 Claude App 打開側邊欄裡釘選的這個頁面，按「複製整則」貼到伴侶 App，貼好按「已轉移」，電腦那邊也會一起更新。

### 用 Codex 或其他 AI

用上面的網址打開頁面。agent 要能「看到並操作這個網頁」才能幫妳寫入，基本以 agent 側欄為主；如果 agent 有操作瀏覽器的功能（例如 Codex），也可以開在妳的慣用瀏覽器裡。

1. **第一次使用：設定同步**：左側「同步與備份」照教學連上妳的 GitHub（只要做一次），手機之後才看得到同樣的記憶。
2. **設定記憶格式**：左側「記憶格式與規則」填妳要的格式、每幾輪一則、字數上限。
3. **新增伴侶，填妳的名字**：左側「＋ 新增伴侶」，再到伴侶頁面上方填妳在這段對話裡的名字。
4. **上傳對話檔**：伴侶頁面的第 1 步，檔案會標上上傳日期。
5. **請 agent 整理並寫入**：agent 看得到這個頁面，不用複製指令，直接跟它說「幫我整理〇〇的對話，寫進記憶匣」。它會自己讀整理指令和對話檔，整理完直接寫進來。
6. **用手機複製、轉移**：手機打開同一個網址，第一次到「同步與備份」貼上連線碼。之後按「複製整則」貼到伴侶 App，貼好按「已轉移」，電腦也會一起更新。

### 沒有 agent 也可以

伴侶頁面下方的三個步驟可以全部手動完成：

1. **上傳對話檔**
2. **交給 AI 整理**：按「複製指令」，連同對話檔一起交給任何 AI（Claude、ChatGPT、Gemini 都可以）
3. **貼回 AI 的回覆**：按「貼上回覆」，把 AI 回的內容整段貼上就好，JSON 或照格式寫好的文字（每則用 `#` 開頭）都可以，也能直接選檔案

## 記憶卡片

預設格式：

```
# [標題]

- 地點：
- 場景概要：
- 關鍵詞：
- 關鍵對話：
- 情感變化及影響：
- {伴侶}覺得重要的事：
```

- `{伴侶}` 會自動換成伴侶的名字
- 欄位名稱有「關鍵詞／關鍵字」會顯示成標籤，有「對話」會顯示成引言
- 「複製整則」照妳的格式輸出：`-` 開頭、標題保留 `# [標題]`、多行的對話會變成縮排的小項目
- 每則下方會顯示字數（預設上限 500 字，含標點），超過會標出來
- 轉移完按「已轉移」收起來，想找回來就切到「已轉移」

## 小提醒

- 記憶格式、每幾輪一則、字數上限，在左側「記憶格式與規則」改，所有伴侶共用。
- 妳的名字、接續方式、整理進度、AI 指令都跟著每位伴侶，各自獨立，都在伴侶頁面上方。
- 每次都匯出完整對話就選「用輪數」接續；每次只匯出新的一段就選「用日期」。整理進度也可以手動修改。
- 每位伴侶的 AI 指令可以按「查看／修改」手動改措辭，改過的地方會記住；之後換名字、進度往前，修改都還會保留。
- 偶爾到「同步與備份」備份一份，比較安心。
- 左側「配色」可以換頁面顏色：草莓氣泡、法式桃紅、午夜唱片、芋泥啵啵。只換樣子，記憶不會變；每台裝置各自記得自己選的配色。

## 同步與備份

- **在 Claude 裡打開**：自動同步到自己的 Claude 帳號，電腦和手機的 Claude 都看得到。
- **從 GitHub 網址打開**：到「同步與備份」用自己的 GitHub 帳號連線（產生一組只開放 gist 權限的金鑰，頁面有一步一步的教學），記憶會存進自己帳號裡的一份私人 Gist。手機打開同一個網址，貼上「手機連線碼」就會看到一樣的內容。
- 兩台裝置同時新增記憶也不會互相蓋掉，會合併在一起。
- 連線碼等同金鑰，只傳給自己；借別人的電腦用完記得「中斷連線」。

## 給 agent

- 頁面提供 `window.memoryShelf`：`help()`、`list()`、`prompt(伴侶名字)`、`readFile(伴侶名字)`、`importMemories(JSON, 伴侶名字)`。詳細寫在 [`AGENT.md`](AGENT.md)。
- agent 看不到網頁、只能讀網址的話，請它先讀 `https://raw.githubusercontent.com/boo-usaki/memory-box/main/AGENT.md` 再整理對話檔。這份是預設格式的指令；改過格式的話，到伴侶頁面按「複製指令」把自己的版本給它。

## JSON 格式

AI 回覆或 agent 產生的檔案，照這個格式就能匯入：

```json
[
  {
    "companion": "伴侶名字",
    "rounds": "1-10",
    "title": "記憶標題",
    "fields": {
      "地點": "……",
      "關鍵詞": ["詞語1", "詞語2"],
      "關鍵對話": "名字：「……」\n名字：「……」",
      "{伴侶}覺得重要的事": "……"
    }
  }
]
```

`fields` 的欄位名稱要跟格式設定裡的一樣。同一位伴侶、同樣 `rounds` 的記憶再次匯入時，會更新原本那則，不會重複。

## 自己架一份

想要自己的網址：fork 這個 repository，到 **Settings → Pages**，Source 選 **Deploy from a branch**、Branch 選 `main`、資料夾選 `/ (root)`，按 Save，等一兩分鐘就會出現網址。
