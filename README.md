# 伴侶記憶匣

*made quietly by Boo_usaki*<br>
<sub>created with Claude Opus 5.5 &amp; Codex (Sol 5.6)</sub>

把妳和 AI 伴侶的長對話，整理成一張張可以複製下來、搜尋和搬進伴侶 App 的記憶卡片。

👉 **[打開伴侶記憶匣](https://boo-usaki.github.io/memory-box/)**

不懂程式也可以使用。打開網頁就能先試；記憶預設只留在妳現在使用的瀏覽器，想讓手機和電腦看到同一份內容時，再開啟同步即可。

## 這個工具會做什麼？

- **記憶**：把長對話依輪數或日期整理成一張張卡片，方便查看與搬運。
- **事件**：挑出關係進展、劇情、日常或人物設定等重要事件，接著寫進伴侶 App 的事件欄。
- **整理進度**：記住上次整理到哪裡，下次從後面接續。
- **待轉移清單**：貼進伴侶 App 後按「已轉移」，畫面就只留下還沒搬完的內容。

記憶匣負責保存和排版；對話內容由妳選擇的 AI 整理。AI 能直接操作頁面時，可以替妳寫入；不能操作頁面時，把 AI 的回覆貼回來也可以。

## 第一次使用

1. 打開記憶匣，按左側「＋ 新增伴侶」。
2. 填上妳在這段對話裡的名字。
3. 選擇要整理「記憶」或「事件」。
4. 把頁面產生的指令和對話檔交給 AI；如果 AI 能操作頁面，也可以直接請它整理並寫入。
5. 整理完成後，按「複製整則」或事件欄的複製按鈕，貼進妳的伴侶 App。

想先換格式、字數或事件類別，再打開左側「記憶格式與規則」。不修改也能直接使用預設值。

## 選擇妳的使用方式

### 我在 Claude 裡使用

如果左上角已經顯示「已同步到 Claude 帳號」，直接新增伴侶就可以開始。之後從電腦或手機的 Claude 側邊欄打開同一份記憶匣，內容會一起更新。

<details>
<summary><strong>第一次把記憶匣放進自己的 Claude 帳號</strong></summary>

1. 在記憶匣的「使用說明」下載 `index.html`，或從這個 GitHub 專案頁面下載同名檔案。
2. 在電腦開一個新的 Claude 對話，附上 `index.html`。
3. 把下面這句整段貼給 Claude：

   > 請把附件的 index.html 發佈成我自己的 Artifact，開啟 db 和 user 功能，完成後幫我釘選到側邊欄。

4. Claude 完成後，點開頁面卡片。左上角出現「已同步到 Claude 帳號」就成功了。

`Artifact`、`db` 和 `user` 是給 Claude 辨認的詞，照貼即可，不需要自己設定或理解。

別人分享的 Claude 頁面只能試看；要保存到自己的帳號，仍要照上面步驟建立自己的那一份。

</details>

### 我從公開網址使用

直接打開 [伴侶記憶匣](https://boo-usaki.github.io/memory-box/) 就能使用，不必先登入 GitHub。

- **只在這台裝置使用**：不用設定同步，資料會留在目前的瀏覽器。
- **手機和電腦要共用**：到左側「同步與備份」，照畫面連上自己的 GitHub 私人儲存空間；手機第一次貼上連線碼即可。
- **使用 Codex 或能操作網頁的 AI**：上傳對話檔後，直接說「幫我整理〇〇的對話，寫進記憶匣」。

### 我的 AI 不能操作網頁

也沒關係，伴侶頁面已經排好三個步驟：

1. 上傳對話檔。
2. 按「複製指令」，把指令和對話檔交給 Claude、ChatGPT、Gemini 或其他 AI。
3. 按「貼上回覆」，把 AI 回傳的內容整段貼回來。

不管 AI 的回覆看起來像一般文字還是程式碼，整段貼回來即可，不需要自己讀懂內容格式。

## 整理記憶

「記憶」適合按照對話順序保存一段段共同經歷。預設每 10 輪整理一張卡片；伴侶一次回覆加上妳一次回覆，算一輪。

頁面會自動記住整理進度。每次都匯出完整對話時，用「輪數」接續；每次只匯出新的一段時，用「日期」接續。

每張卡片都可以：

- 複製整則
- 編輯內容
- 標記為「已轉移」
- 在「待轉移／已轉移」之間切換查看

<details>
<summary><strong>看看預設的記憶格式</strong></summary>

```text
# [標題]

- 地點：
- 場景概要：
- 關鍵詞：
- 關鍵對話：
- 情感變化及影響：
- {伴侶}覺得重要的事：
```

`{伴侶}` 會自動換成伴侶名字。預設每張卡片最多 500 字；格式、輪數和字數都能在「記憶格式與規則」修改。

</details>

## 整理事件

「事件」適合保存真正重要、之後希望伴侶記得的事情，例如關係進展、劇情、日常紀錄或人物設定。

1. 在伴侶頁面右上角切換到「事件」。
2. 選擇事件類別和要整理的日期範圍。
3. 把指令與對話檔交給 AI，再讓 AI 直接寫入或把回覆貼回來。
4. 按事件欄上的「大標」「小標」「內文」，分別複製到伴侶 App。

匯入後，記憶匣會自動記住整理到哪一天。如果 AI 漏寫日期、日期對不上或超出妳選的範圍，頁面會提醒妳檢查，不會擅自跳過那段對話。

當下一則放不進目前事件欄時，頁面會先詢問妳：

- 改短一點，放進這欄；或
- 結束目前這欄，開新的一欄。

如果單則內容本身就超過字數上限，只會請妳改短，不會先把超長內容存進去。

<details>
<summary><strong>事件代號、欄位與接續設定</strong></summary>

- 預設類別有 FIR（關係重大進展）、EV（劇情進展）、DIA（日常紀錄）、CS（人物設定）、STORY（人物故事）。名稱和類別都可以修改。
- 不喜歡 `[FIR-05-02]` 這類代號，可以在「記憶格式與規則 → 事件格式」改成「不用代號」。
- 伴侶 App 裡已經有寫到一半的事件欄時，在事件頁按「接著寫」，貼上原有內文；記憶匣會算出下一個編號。
- 刪除一則事件後，後續編號不會倒退或重複使用。
- 預設每則事件最多 500 字、每欄最多 2000 字，兩個數字都能修改。

預設格式：

```text
[{代號}-{欄號}-{則號}] {關鍵字}
時間：
地點：
細節：
```

</details>

## 資料存在哪裡？

| 使用方式 | 記憶存放位置 | 手機、電腦共用 |
| --- | --- | --- |
| 公開網址，沒有開同步 | 目前這個瀏覽器 | 不會 |
| 公開網址，開啟 GitHub 同步 | 妳自己的私人儲存空間（Gist） | 會 |
| 妳自己的 Claude 版本 | 妳自己的 Claude 帳號 | 會 |

- 每個人打開公開網址，看到的都是自己的資料；分享網址不會把妳的記憶一起分享出去。
- 上傳的原始對話檔不包含在同步或備份裡。換裝置後如需重新整理，請在新裝置再次上傳。
- 記憶匣本身不會把大家的內容集中存到作者帳號；但妳把對話交給哪個 AI 整理，仍適用那個 AI 服務自己的隱私與資料規則。
- 建議偶爾到「同步與備份」複製或下載一份備份。備份包含記憶、事件和設定，不含原始對話檔。
- GitHub 連線碼等同金鑰，只傳給自己；在別人的電腦使用後，記得按「中斷連線」。

## 常見問題

**一定要設定同步嗎？**

不用。只在同一個瀏覽器使用時可以完全不設定；需要手機和電腦共用時再開啟。

**AI 一定要能操作網頁嗎？**

不用。不能操作時，使用「複製指令」與「貼上回覆」即可。

**一定要使用事件代號嗎？**

不用。事件格式可以切換成「不用代號」。

**格式一定要照預設嗎？**

不用。記憶與事件格式、字數、事件類別都能修改；每位伴侶也能另外調整自己的 AI 指令。

**可以只用手機嗎？**

可以瀏覽、複製與標記轉移；第一次建立自己的 Claude 版本或設定 GitHub 同步，用電腦操作會比較方便。
