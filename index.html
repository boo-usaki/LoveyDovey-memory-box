      Guide
      使用說明
      
      
    
      
    
      
      
      先看這裡
      
      
      不需要懂程式。流程是：在電腦上請 AI 整理對話 → 用手機打開同一個網址，複製貼進伴侶 App。
      
      
      記憶匣只有一個正式網址：boo-usaki.github.io/memory-box。電腦和手機都從這裡打開，建議加入書籤。
      
    
      
    
        
      
      1. 在電腦打開正式網站
        用電腦的瀏覽器打開上面的網址。只在這台電腦使用時，不用登入，也不用設定。
        2. 
      
      2. 需要手機共用時，設定一次同步
        到左側「同步與備份」，照步驟連上妳自己的 GitHub，記憶會存進妳帳號裡的一份私人 Gist。只要在電腦設定一次。
        3. 
      
      3. 新增伴侶，選「記憶」或「事件」
        按左側「＋ 新增伴侶」輸入名字，再到伴侶頁上方填妳在這段對話裡的名字。記憶會依對話順序整理成卡片；事件只挑出之後希望伴侶記得的重要事情，要再選類別和日期範圍。格式、輪數和字數都有預設值，想改再到「記憶格式與規則」。
        4. 
      
      4. 在電腦上傳對話檔，請 AI 整理
        
        能操作網頁的 AI：讓它打開這個網址，跟它說「幫我整理〇〇的對話，寫進記憶匣」，它會自己讀檔、整理、寫入。
        
        
        不能操作網頁的 AI：按「複製指令」，連同對話檔一起交給它；它回覆後，按「貼上回覆」貼回記憶匣。
        
        
        事件會自動編號，接在目前的事件欄後面；放不下時，頁面會先問妳要改短還是開新欄。
        5. 
      
      5. 手機打開同一個網址，貼上連線碼
        在電腦的「同步與備份」按「複製手機連線碼」傳給自己；手機打開同一個網址，到「同步與備份」貼上，就會看到一樣的內容。只要第一次做。
        6. 
      
      6. 在手機複製，貼進伴侶 App
        按「複製整則」；事件則分別複製大標、小標和內文，自己貼進伴侶 App。貼好後按「已轉移」，電腦那邊也會一起更新。
        7. 
    
      
    
      
      
      記憶卡片長這樣
      
      
      這只是示意，不會存進妳的記憶匣。
      
      
      
    
      
    
      
      
      小提醒
      
      
        
        
      • 不調整任何設定也能使用。想換記憶格式、事件類別或字數，再到「記憶格式與規則」。
        • 
        
      • 「記憶」適合依順序保存長對話；「事件」適合挑出關係進展、劇情或人物設定等重要事情。
        • 
        
      • 每次都匯出完整對話就選「用輪數」接續；每次只匯出新的一段就選「用日期」。
        • 
        
      • 事件欄快滿時，頁面會先問妳要改短還是開新欄，不會自己決定。
        • 
        
      • 偶爾到「同步與備份」留一份備份；原始對話檔不會包含在同步或備份裡。
        •

      01跨裝置同步
      
      
      
      
      
        
        
          
      1. 到 GitHub 產生同步金鑰
        登入 GitHub 後打開 這個連結，權限已經只勾好「gist」。有效期限（Expiration）選妳想要的長度，按最下面的「Generate token」。
        2. 
          
      2. 貼到下面按「連線」
        複製 ghp_ 開頭的那串。頁面會在妳的 GitHub 建一份私人 Gist 存記憶。
        3. 
          
      3. 手機或其他電腦
        連線後按「複製手機連線碼」，傳給自己，在手機打開同一個網址、貼到這裡就好。
        4. 
        
      
        
      
          
        
      
        
      
      
      
      
      
        
      
        
      
          
          
          
        
      
        
      連線碼等同金鑰，只傳給自己，不要貼到公開的地方。借別人的電腦用完，記得按「中斷連線」。
      
      
      
      
      
    
      
    
      
      
      02備份
      
      
      記憶只存在這個瀏覽器裡，換裝置或清除瀏覽器資料就會不見。定期備份比較安心。
      
      
      備份包含全部記憶、事件、事件欄、伴侶設定、記憶與事件格式和 AI 指令的修改；不含上傳的對話檔。
      
      
      
        
        
        
      
      
      
      
        
      貼上備份內容或選擇備份檔。還原會用備份取代目前全部的記憶、事件和設定，建議先複製一份現在的備份。
